# Archived — superseded drafts

The files in this folder are early, now-superseded artifacts. **They are not
the current proposal.** The authoritative, actively maintained proposal is
the Google Doc linked from the repository root [README.md](../../README.md).

- `Beverage_Warehouse_Proposal.pdf`, `beverage_standalone.html`, `proposal.html`
  — an early standalone export of the proposal (created 2026-06-16). Several
  sections have since been revised in the Google Doc, most notably the budget
  (this draft: $0–$150 dev / $51–$121 month, excluding labor; current
  proposal: $10,000 total, including team labor) and the barcode approach
  (this draft: phone-camera primary; current proposal: hardware USB/Bluetooth
  scanner default, phone camera optional).
- `Software Project Proposal Format.pdf` — the generic assignment format
  template the proposal was written against, not project-specific content.

Kept for reference only. Do not cite figures from these files as current.
